Processing logic

Each filtering function takes a prepared dataset and returns an updated object containing the retained features, removed feature IDs, and filter-specific results.

  • Individual filtering calls follow your chosen order. Pass the result of one step to the next. Each step operates on the features retained by the preceding steps, so changing the order can change the results.
  • Each filtering stage can be applied once per object: blank, MS, QC and peak filtering. To change settings or repeat a stage, start again from the saved object immediately before that stage.
  • mc_run() uses a fixed stage order: blank → MS → QC → peak. Stages set to NULL are skipped.
  • MS subfilters run sequentially in a fixed order: isotopes → adducts → neutral losses → in-source fragments → mispicked ions → ringing/saturated ions. Only selected subfilters run. Their order in the filters vector does not change the processing order.
  • QC and peak criteria are combined within their respective stages. A feature must satisfy every selected criterion. For QC, mode determines how results from the evaluated groups are combined.
  • Plotting uses the stored filtering results. It does not rerun filtering. A stage-specific plot requires that stage to have been applied.
  • Final tables and exports use the current retained features. mc_final_table(), mc_write_table() and mc_export() default to format = "input", restoring the original input-table layout.

library(MetaboCensoR)
peak_file <- system.file(

Complete MS and peak parameter dictionaries

These are defaults. Only the tolerance matching "da" or "ppm" is used. Explicit filters in a filtering call override the enable flags. Use "positive" or "negative" for polarity.

ms_options <- mc_ms_parameters(
  # ISOTOPE FILTERING
  # Enable isotope filtering when mc_filter_ms(filters = NULL). An explicit
  # filters vector overrides this flag; use "isotopes" to select isotope
  # filtering explicitly.
  enable_iso2 = TRUE,
  # Minimum Pearson correlation between the sample-intensity profiles of a
  # candidate isotope and its parent feature. Values range from 0 to 1; higher
  # cutoffs require more similar profiles.
  iso_cor2 = 0.8,
  # Maximum retention-time difference, in minutes, between a candidate isotope
  # and its parent feature.
  iso_rt2 = 0.01,
  # Mass-tolerance unit for isotope matching: "da" uses iso_mz_tol2; "ppm" uses
  # iso_ppm2. Only the selected tolerance is used.
  iso_tol_type2 = "da",
  # Absolute mass tolerance in Da for isotope matching. Used only when
  # iso_tol_type2 = "da".
  iso_mz_tol2 = 0.005,
  # Relative mass tolerance in ppm for isotope matching. Used only when
  # iso_tol_type2 = "ppm".
  iso_ppm2 = 10,
  # Maximum charge state searched for isotope relationships. For example, 3
  # searches charge states 1, 2 and 3.
  iso_zmax2 = 3,
  # Maximum isotope order k searched. Expected isotope spacing is 1.00336 * k / z
  # Da, for orders 1 through iso_n2 and charges 1 through iso_zmax2.
  iso_n2 = 1,
  # Number of additional dimer-pattern isotope shifts searched: 1.00336 * (j +
  # 0.5) Da for j from 1 through iso_nd2.
  iso_nd2 = 3,
  # ADDUCT FILTERING
  # Enable adduct filtering when mc_filter_ms(filters = NULL). An explicit
  # filters vector overrides this flag; use "adducts" to select adduct filtering
  # explicitly.
  enable_add2 = TRUE,
  # Ionization polarity used to select adduct definitions: "positive" or
  # "negative". Set nl_pol2 separately if neutral-loss filtering is also used.
  add_pol2 = "positive",
  # Minimum Pearson correlation between the sample-intensity profiles of features
  # proposed to belong to the same adduct family. Values range from 0 to 1;
  # higher cutoffs require more similar profiles.
  add_cor2 = 0.8,
  # Maximum retention-time difference, in minutes, between features proposed to
  # belong to the same adduct family.
  add_rt2 = 0.005,
  # Mass-tolerance unit for adduct matching: "da" uses add_mz_tol2; "ppm" uses
  # add_ppm2. Only the selected tolerance is used.
  add_tol_type2 = "da",
  # Absolute mass tolerance in Da for adduct matching. Used only when
  # add_tol_type2 = "da".
  add_mz_tol2 = 0.005,
  # Relative mass tolerance in ppm for adduct matching. Used only when
  # add_tol_type2 = "ppm".
  add_ppm2 = 10,
  # Minimum candidate neutral mass in Da for adduct annotation. Candidate neutral
  # masses must be strictly greater than this threshold.
  add_min_nm2 = 50,
  # If TRUE, restrict the total retention-time spread of an adduct family to

  add_strict_rt2 = TRUE,
  # Prefer selected ion forms when choosing adduct-family representatives.
  # Retain the most intense qualifying preferred feature, or the most intense feature overall

  # For example, c("M+H", "M+Na").
  add_preferred2 = NULL,
  # Maximum intensity decrease (%) from the family's highest mean intensity 
  # for a preferred representative.
  add_prefer_pct2 = 10,

  # filters vector overrides this flag; use "neutral_losses" to select neutral-

  enable_nl2 = FALSE,
  # Ionization polarity used to select neutral-loss definitions: "positive" or

  # Absolute mass tolerance in Da for neutral-loss matching. Used only when

  ring_tol_type2 = "da",

QC and blank recipes

QC examples below illustrate options. group_any requires at least one group to pass each metric, group_every requires all selected groups, and pooled combines selected samples. Selected metrics are combined with AND. D-ratio requires a genuine QC group and enough replicate samples.

after_blank <- mc_filter_blank(imported, groups = "Blank",
                               mode = "mean_cutoff", cutoff = 0.10)
# Alternative, starting again from imported:
after_detected <- mc_filter_blank(imported, groups = "Blank",
                                  mode = "drop_detected")
after_qc <- mc_filter_qc(
  imported, filters = c("zeros", "mean", "rsd", "min"),
  mode = "group_every", groups = "Sample",
  zero_metric = "percent", zero_cutoff = 50,
  mean_cutoff = 5000, rsd_cutoff = 30, min_cutoff = 1000
)

Functions and arguments

Each template shows the complete argument list. Choice vectors in templates list allowed alternatives; normally select one string. ... in parameter constructors accepts the named settings listed above.

mc_prepare

Read a feature-by-sample peak table, identify intensity columns, and assign sample groups. Feature metadata are retained alongside the intensity values.

# mc_prepare(data, type = c("mzmine", "generic", "xcms", "msdial"), 
#     sample_cols = NULL, sample_keywords = NULL, id_col = NULL, 
#     mz_col = NULL, rt_col = NULL, labels = NULL, token_sep = "_", 
#     token_index = 2)
  • data: A local CSV filename or a data frame with one feature per row. Bundled files can be located with system.file(). For a web-hosted CSV, first read it with vroom::vroom(url, delim = ",") and pass the resulting table.
  • type: Input format: "mzmine" (default), "generic", "xcms", or "msdial". XCMS retention times are converted from seconds to minutes. Other formats require retention times in minutes. See compatible peak-table examples for the supported input layouts.
  • sample_cols: Intensity-column names or integer column positions after format conversion and column cleanup. Explicit selections take precedence over sample_keywords.
  • sample_keywords: Case-sensitive literal substrings used to identify intensity columns. A column is selected if its name contains at least one substring. If neither selector is supplied, columns with at least 70% finite numeric entries are considered, excluding identified feature columns and names beginning with row.
  • id_col: Feature-ID column name. If omitted, searches for row ID, Feature ID, or Alignment ID, then uses the first column. Original names recognized during format conversion may also be supplied.
  • mz_col: Feature m/z column name. Defaults to the standardized mz column; recognized original column names are accepted.
  • rt_col: Retention-time column name. Defaults to the standardized rt column; recognized original column names are accepted.
  • labels: One nonempty group label per sample. An unnamed vector must follow the selected sample columns; a named vector is matched to their names. If omitted, groups are extracted from sample names using token_sep and token_index.
  • token_sep: Literal separator used to split sample names when labels are omitted. Default: "_".
  • token_index: One-based position of the group name in each split sample name. Default: 2.

mc_labels_from_names

Split each sample name at a chosen separator and use one part as its group label.

# mc_labels_from_names(sample_names, separator = "_", token = 2)
  • sample_names: Character vector of sample-column names, in the required output order.
  • separator: Literal separator, not a regular expression. Default: "_".
  • token: Positive integer giving the one-based position of the group name. Default: 2.

mc_labels_from_metadata

Read sample names and groups from two metadata columns and align the group labels to the peak-table sample order.

# mc_labels_from_metadata(path, sample_names, sample_col, label_col, clean_names = FALSE, 
#     remove_suffixes = NULL)
  • path: Local metadata CSV filename. The first row must contain column names. Download remote files before calling this function.
  • sample_names: Sample-column names to match, in the required output order.
  • sample_col: Exact metadata column name containing sample identifiers.
  • label_col: Exact metadata column name containing group labels.
  • clean_names: If TRUE, also remove the suffixes specified in remove_suffixes from both sets of names before matching. Default: FALSE.
  • remove_suffixes: Optional trailing strings to remove, for example c(" Peak area", ".mzML"). Suffix removal is case-insensitive and is used only when clean_names = TRUE.

mc_labels_from_csv

Read a headerless CSV containing one sample-group label per row.

# mc_labels_from_csv(path, sample_names)
  • path: Filename of a comma-separated, headerless label file. The first column is read as the label vector.
  • sample_names: Sample-column names in the same order as the labels in the file.

mc_filter_blank

Compare feature intensities in blank and experimental groups, or remove every feature detected in a blank sample. Save the values and decisions for inspection and plotting.

# mc_filter_blank(x, groups, mode = c("mean_cutoff", "drop_detected"), 
#     cutoff = 0.1, labels = NULL)
  • x: A metabocensor_result returned by mc_prepare() or a filtering function.
  • groups: One or more existing group labels identifying blanks, for example "Blank". All remaining groups are treated as experimental groups in ratio mode.
  • mode: "mean_cutoff" (default) compares blank and experimental group means. "drop_detected" removes any feature with intensity greater than zero in any selected blank sample.
  • cutoff: Nonnegative blank-to-sample ratio threshold, default 0.10. Used only in "mean_cutoff" mode. A ratio equal to the cutoff does not pass.
  • labels: Optional sample-group labels. An unnamed vector must follow x$sample_cols; a named vector must cover those sample names exactly. NULL uses x$labels.

mc_filter_qc

Calculate zero abundance, mean intensity, relative standard deviation, D-ratio, or minimum intensity for selected sample groups, then retain features that pass every selected metric.

# mc_filter_qc(x, filters = character(), mode = c("group_any", "group_every", 
#     "pooled"), groups = NULL, zero_metric = c("count", "percent"), 
#     zero_cutoff = 1, mean_cutoff = 5000, rsd_cutoff = 30, min_cutoff = 1000, 
#     qc_group = NULL, dratio_cutoff = 50, labels = NULL)
  • x: A metabocensor_result returned by mc_prepare() or a filtering function.
  • filters: Character vector containing any of "zeros", "mean", "rsd", "dratio", and "min". The default empty vector removes nothing.
  • mode: "group_any" (default): each metric must pass in at least one selected group. "group_every": each metric must pass in every selected group. "pooled": combine selected samples before calculating each metric.
  • groups: Group labels to evaluate. NULL or an empty vector selects all groups. For D-ratio, the group specified by qc_group is excluded from the biological denominator. Select biological groups explicitly to avoid including blanks.
  • zero_metric: Express zeros as "count" or "percent" of evaluated samples.
  • zero_cutoff: Zero-count or zero-percentage threshold. Default: 1. Features pass only when their zero count or percentage is strictly less than this threshold. With "zero_metric" = "count", a cutoff of 1 allows no zeros. With "zero_metric" = "percent", a cutoff of 50 rejects features with exactly 50 percent zeros.
  • mean_cutoff: Minimum arithmetic mean intensity. Equality passes. Default: 5000.
  • rsd_cutoff: Maximum RSD in percent. Equality passes. Default: 30.
  • min_cutoff: Minimum observed intensity. Equality passes. Default: 1000.
  • qc_group: Exactly one existing pooled-QC group label for D-ratio, containing at least two samples. Required only when dratio is selected.
  • dratio_cutoff: Maximum D-ratio in percent. Equality passes. Default: 50.
  • labels: Optional sample-group labels. An unnamed vector must follow x$sample_cols; a named vector must cover those sample names exactly. NULL uses x$labels.

mc_filter_ms

Apply isotope, adduct, neutral-loss, in-source-fragment, mispicked-ion, and ringing-artifact filters. Retain representative features and expose the annotation tables for inspection.

# mc_filter_ms(x, filters = NULL, parameters = mc_ms_parameters(), 
#     adducts = NULL, neutral_losses = NULL, spectra = NULL)
  • x: A metabocensor_result returned by mc_prepare() or a filtering function.
  • filters: Any of "isotopes", "adducts", "neutral_losses", "isf", "mispicked", and "ringing". An explicit vector overrides enable flags in parameters. NULL uses those flags; isotopes and adducts are enabled by default. character(0) disables all subfilters.
  • parameters: Named list from mc_ms_parameters(). Pass your list explicitly with parameters = ms_options.
  • adducts: Custom adduct data frame or local CSV filename. NULL uses built-in definitions. Required columns are described below.
  • neutral_losses: Custom neutral-loss data frame or local CSV filename. NULL uses built-in definitions. Required columns are described below.
  • spectra: A Spectra object, for example from mc_read_mgf(). Required for ISF when MS2 checking is enabled.

mc_filter_peak

Apply selected feature-property bounds or match a list of m/z and retention-time targets. Store values and filtering decisions for plotting.

# mc_filter_peak(x, filters = NULL, parameters = mc_peak_parameters(), 
#     targets = NULL, target_text = NULL)
  • x: A metabocensor_result returned by mc_prepare() or a filtering function.
  • filters: Any of "mz", "rt", "rmd", "amd", and "target". NULL uses parameters$peak_filters; the default selects no filters.
  • parameters: Named list from mc_peak_parameters(), specifying enabled bounds and target-matching tolerances.
  • targets: Target data frame or local CSV filename with m/z and retention time in minutes. Use columns named mz and rt; if recognizable names are absent, the first two columns are used.
  • target_text: Optional comma-separated target rows as one string, with or without a header. These rows are combined with targets and duplicate m/z-RT pairs are removed.

Results, annotation tables and plots

Each stage can be applied once to an object. To change a stage, start from the saved object before that stage. Individual calls can use different stage orders; mc_run() always uses blank, MS, QC, then peak. MS subfilters have their own fixed order.

after_ms <- mc_filter_ms(
  after_blank, filters = c("isotopes", "adducts", "isf"),
  parameters = ms_options, spectra = spectra, adducts = adduct_file
)
